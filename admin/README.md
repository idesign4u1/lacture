# מערכת ניהול מקומית — לוח שנה יהודי

## הפעלה

```bash
cd admin
npm install
npm start
```

פתח דפדפן בכתובת: **http://localhost:3030**

## יכולות

| טאב | תיאור |
|-----|-------|
| 🛠️ כלים | הפעלה/כיבוי של כל כלי בנפרד — שינוי מיידי |
| ✏️ תוכן | עריכת הודעות חיזוק יומי + טקסט פתיחה של הבוט |
| 🎨 עיצוב | בחירת צבע ראשי מ-9 ערכות |
| 📤 Git | שמירה + דחיפה לענף הפיתוח |

## זרימת עבודה

1. הפעל `npm start`
2. ערוך את ההגדרות בדפדפן
3. לחץ **"שמור שינויים"** — נשמר ב-`config.json`
4. לחץ **"שמור ודחוף ל-Git"** — מבצע commit+push לענף
5. ב-Android Studio: `Git → Pull`
